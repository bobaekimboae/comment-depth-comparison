# 댓글 뎁스 구조 비교

커뮤니티 댓글 스레드의 계층 구조와 연결선 UI를 한 페이지에서 비교하는 인터랙티브 시안입니다.

## 목적

Threads, Reddit, YouTube, Facebook, 네이버 카페, 보배드림 권장안의 댓글 계층 구조와 UX를
같은 대화 내용으로 나란히 비교합니다. 뎁스 제한, 연결선 유무, 들여쓰기 폭, 접기·더보기 방식의
차이가 가독성과 모바일 본문 폭에 어떤 영향을 주는지 확인할 수 있습니다.

## 비교 항목

| # | 구조 | 특징 |
|---|------|------|
| 1 | Threads형 · 얕은 대화 | 단일 수직 라인 / 작성자 레일로 연결 / 얕은 대화(1~2뎁스)에 적합 |
| 2 | Reddit형 · 깊은 트리 | 깊이별 수직 + 가로선 / 깊은 토론에 적합 / 모바일 본문 폭 감소 |
| 3 | YouTube형 · 3뎁스 후 평탄화 | 최대 3뎁스 / 이후 답글은 같은 폭 / 긴 대화의 가로폭 보호 |
| 4 | Facebook형 · 1단 들여쓰기 | 연결선 없음 / 원댓글 아래 1단 들여쓰기 / @멘션으로 답글 대상 표시 |
| 5 | 네이버 카페형 · 1단 답글 | 연결선 없음 / 원댓글과 답글만 구분 / 국내 커뮤니티에 익숙한 방식 |
| 6 | 보배드림 권장 · 3뎁스 + 접기 | 최대 3뎁스 연결선 / 이후 답글은 접기·더보기 / 가독성과 긴 토론 관리의 균형 |

## 사용법

각 카드의 `답글 보기`, `답글 더보기`, `대화 접기` 버튼을 클릭해 뎁스 표현과 접기 동작을 확인하세요.
모든 버튼은 `<button>` 요소라 키보드(Tab → Enter/Space)로도 조작할 수 있습니다.

## 구성

- `index.html` — 외부 라이브러리·이미지·API 없이 동작하는 단일 HTML 파일 (PC/모바일 반응형)
- 폰트: Pretendard, 시스템 산세리프 fallback
